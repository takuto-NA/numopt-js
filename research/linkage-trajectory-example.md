# 固定した四節リンクでの軌跡フィッティング

機構の接続を決めた後、寸法の連続最適化だけで目標軌跡へ近づけられるかを、実行可能なExampleとベンチマークで検証する。Coros et al. (2013) §4.2に相当する合成問題であり、論文のキャラクターデータを使った追試ではない。学習・SQP・機構の自動生成は使わない。既存の公開APIだけで実装し、ライブラリの最適化アルゴリズムは変更していない。

## 実行

```sh
npm ci
npm run example:linkage-trajectory
npm run benchmark:linkage-trajectory
```

Exampleは`benchmark-results/linkage-trajectory-example.{html,json}`を生成する。HTMLをブラウザで開くと、記録された全反復の軌跡・物理的なリンク長・入力位相を操作できる。入力クランクを回してリンクの姿勢と目標との対応点も見られる。最適化自体はTypeScript側で実行しており、HTMLは計算済みデータの再生である。外部通信・追加のUI依存関係はない。

ベンチマークは`benchmark-results/linkage-trajectory-benchmark.{md,json}`を生成する。生の各試行・パラメータ履歴・時間の中央値/IQR・実行環境・ソースハッシュを保存する。精度基準を満たさない場合は終了コード1となる。結果ファイルはgitignore対象。

静止画はMatplotlibを利用して任意に生成できる。Node側のExampleとベンチマークにはPythonは不要。

```sh
python -m pip install matplotlib
python scripts/plot-linkage-trajectory.py
```

## 固定するものと調整するもの

| 要素 | 設定 |
|---|---|
| 接続 | O–A–B–D–Oの四節リンクを固定 |
| 固定支点 | O=(0,0)、D=(g,0)、g≈2.429606を固定 |
| マーカー | 連接棒上の座標(u,v)=(2.6,0.45)を固定。Aを原点、AB方向とその法線で表す |
| 設計変数 | クランクa、連接棒b、ロッカーcの3長さのみ |
| 入力 | クランクの位相θ。最適化中に位相や速度の対応は変更しない |
| 状態 | 各位相の連接棒角β、ロッカー角γ。閉路制約を数値的に解く |
| 組立分岐 | 上側の同一分岐を維持し、独立した幾何解との一致を検査 |
| 単位 | 無次元。製造誤差や実機精度の評価ではない |

設計変数pは3次元で、物理長さは`a=0.45+0.10*tanh(p0)`、`b=2.10+0.15*tanh(p1)`、`c=1.80+0.15*tanh(p2)`。この範囲は全回転可能な正則領域に収まり、最適化中にトグル姿勢へ入る問題を避ける。支点間隔とマーカー座標は、設計ベクトルの成分として存在しない。

目標は別の寸法から円交点で作った到達可能な軌跡と、それに`0.02*[cos(3θ),sin(3θ)]`を加えた変形軌跡の2種類。どちらも最適化中は不変。既知の正解寸法は合成データ生成と検証に使い、ソルバーの初期値や解として渡さない。

目的関数は`f(p)=1/(2N) Σ ||m(p,θ_i)-target(θ_i)||²`。同じ入力位相の位置を合わせるため、点集合の最近傍距離による形状合わせとは異なる。何も寸法を変えず、完全に固定した剛体機構の軌跡を変更できる、という意味ではない。

## 解法と独立検証

主経路は公開`gaussNewton`で各位相の閉路状態を解き、公開`computeEffectiveJacobian`を位相ごとの2×2状態ブロックへ適用し、公開`bfgs`で3寸法を更新する。C_pだけを状態固定の中央差分で求め、状態・マーカーの偏微分は解析式を使う。

比較は同じBFGSでコスト全体を中央差分する経路と、解析的な一次偏微分を与えた公開`constrainedLevenbergMarquardt`。全差分は各摂動で状態を数値的に解き直す。LMは周期全体の密行列を使うため、BFGSとの時間差には数値モデルと行列の組み立て方の両方が含まれる。LMの生の返却コスト・コールバックはSSEなので、Example側の履歴アダプターで0.5*SSEへ揃える。

- 最適化には32位相。検証は257位相、オフセット0.37の別格子。最適化格子との重複がないこともテストする。
- 最終軌跡は、最適化に使っていない円交点解で再計算する。検証格子でも数値組立と幾何解の分岐が一致することを確認する。
- 到達可能目標は、未使用位相での**最大**位置誤差`<=1e-5`を要求する。
- 変形目標は目的関数90%以上減少、独立した解析縮約勾配ノルム`<=1e-8`、残差がゼロにならないことを確認する。
- 両方でリンク閉路・組立分岐の誤差`<=1e-9`、有限な評価値、全記録反復の目的関数減少とコストの再計算一致を要求する。`converged`フラグは独立に表示する。
- 3初期値×2目標×3手法を、条件ごとにウォームアップ1回を捨てて3回計測する。計54回。検証と描画は計測に含めない。

## この環境での結果

54/54試行が精度基準を通過した。全体のユニットテストも343/343件通過。ブラウザでは反復・位相・目標の切替と再生、360px幅の表示を確認した。

代表初期値`p=[-0.9,0.8,-0.7]`の公開IFT+BFGSは次の結果となった。

| 目標 | 初期RMS | 最終の未使用257位相RMS | 最大位置誤差 | 閉路制約ノルム |
|---|---:|---:|---:|---:|
| 到達可能 | 0.21849 | 約2.7e-12 | 約3.2e-12 | 約3.0e-13 |
| 変形あり | 0.21941 | 約0.02000 | 約0.02004 | 約3.1e-13 |

代表例の最終コールバックは反復番号26、返却`iterations`は初期点の評価を含む27。長さはおおよそ`[0.378370,2.199606,1.709345]`から`[0.479131,2.049544,1.836738]`へ変わり、支点間隔・マーカー取付位置は一定のまま。

これにより、**接続を決めた機構の寸法を変え、固定された対応付き目標軌跡へ近づける連続最適化**は、現状の機能で実装・実行できることを確認した。変形目標の結果は、この設計範囲・初期値での局所的な停留解であり、大域最適性や任意の軌跡の実現を証明するものではない。機構トポロジー探索、干渉・強度・製造性、特異点や分岐を横断する設計は別の課題となる。
