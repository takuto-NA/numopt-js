# Computational Design of Mechanical Characters と numopt-js

対象は [Coros et al., Computational Design of Mechanical Characters, SIGGRAPH 2013](https://publications.ri.cmu.edu/storage/publications/pub_files/2013/0/CDMC_final.pdf)。論文の章・式番号を以下に示す。これは著者のキャラクター・機構パラメータ・訓練データを用いた実験再現ではなく、既存APIの適用範囲の調査と、§4.2の数式を使った新しい4節リンクの検証である。

## 必要な連続最適化は実装されているか

**本ブランチでは§4.2の局所的な機構パラメータ最適化に必要な改善を実装した。学習・SQP・不等式ソルバーは追加していない。** 論文全体のパイプラインの実装とは区別する。

| 論文の処理 | 現在の実装 | 適用範囲・不足 |
|---|---|---|
| §3.2, Eq. (1): 接続制約の二乗和を最小化して状態を解く | `gaussNewton`, `levenbergMarquardt` | 目的は同じ形。論文が使う完全なNewton-Raphsonと同一アルゴリズムではない。機構ごとの制約関数を利用者が与える。 |
| §4.2, Eq. (2): 位相ごとのマーカー軌跡誤差 | スカラー目的＋`bfgs`、または残差＋制約付きGN/LM | 位相のサンプリング、マーカー座標、求解の接続はExample側で構成する。 |
| §4.2, Eq. (3-4): 陰関数微分 | `computeEffectiveJacobian`、`EffectiveJacobianOptions`を公開 | `J_eff = r_p - r_s C_s^+ C_p`。`J_eff^T r`を公開BFGSに渡せる。状態の求解は利用側が担当し、Exampleに接続例を含める。 |
| §4.2: BFGS更新 | `bfgs`, `adjointBfgs` | 随伴は同じ縮約勾配を与える。論文自体は随伴法ではなく前進感度を記述している。 |
| §4.2: 冗長制約による縦長の `C_s` | 公開有効ヤコビアン＋BFGS、制約付きGN/LM | 整合し列フルランクの矩形系を扱える。Adjoint系の正方制約の契約は維持。 |
| §5.2, Eq. (7-8): 曲線メトリックの学習 | 専用ソルバーなし | 不等式制約が必要。論文はSQPを使う。対角メトリックでは二乗してLPに変形できるが、LPソルバーも未実装。 |
| §6.1, Eq. (9): 歯車半径・位置・角速度の最適化 | 専用ソルバーなし | 等式＋非線形不等式制約を扱うSQP等が必要。現在の制約付きGN/LMは一般の不等式付きNLPソルバーではない。 |

`adjointNewton` / `adjointNewtonExact`も存在するが、§4.2の再現に必要な条件ではない。SQPの代わりにもならない。ペナルティ最小二乗への置換は可能でも、元の不等式制約の厳密な充足や同一手法の再現を意味しない。

§5.2の学習、§6.1の歯車配置、§6.2の離散CSPは今回の実装対象外とした。機構の接続モデル、検索データベース、曲線特徴、非円形歯車、形状生成と製造工程もライブラリの最適化APIだけでは完成しない。

## 実行

リポジトリのルートで実行する。

```sh
npm run example:mechanical-character
npm run benchmark:mechanical-character
npm test -- --run test/mechanicalCharacter.test.ts
```

Exampleは各手法を1回実行する。ベンチマークはwarmupを1回捨て、3回の中央値とIQRを出力する。勾配単体は7回測定する。JSON・Markdownはgitignoredな`benchmark-results/mechanical-character.{json,md}`へ保存する。

**厳しい精度基準に未達の手法がある場合、Exampleとベンチマークはexit code 1を返す。** 本ブランチの計測では全14条件×3回が通り、exit code 0となった。回帰テストでも全7手法について、到達可能なターゲットの精度と、非ゼロ残差のターゲットでの停留性を検証する。

任意の図出力はMatplotlibのあるPythonで行う。

```sh
python scripts/plot-mechanical-character.py
```

図は`benchmark-results/mechanical-character.png`へ保存される。通常のExample・ベンチマークにPythonは必要ない。

## 機構と目的関数

原点のクランク支点、`(g,0)`のロッカー支点、長さ`a,b,c`のクランク・カプラー・ロッカーを使う。入力位相を`theta`、状態をカプラー角`beta`とロッカー角`gamma`とする。

```text
C(p,s) = [a cos(theta) + b cos(beta) - g - c cos(gamma),
          a sin(theta) + b sin(beta)     - c sin(gamma)]
marker = a [cos(theta),sin(theta)]
       + u [cos(beta),sin(beta)] + v [-sin(beta),cos(beta)]
F = (1 / (2N)) sum_t ||marker(p,s_t(p)) - target_t||^2
```

設計変数は6個で、4個の長さ用潜在変数とマーカーのローカル座標`u,v`。長さは`center + range * tanh(p)`で正値と全回転可能な領域を保証する。中心は`[0.45,2.1,1.8,2.4]`、範囲は`[0.1,0.15,0.15,0.15]`。クランク先端と固定支点の距離は常に`[1.7,3.1]`内、`|b-c| <= 0.6`、`b+c >= 3.6`となり、接触・一直線の特異姿勢を避ける。一般の機構で分岐・ロック・特異姿勢を解決した実験ではない。

初期値は`[0,0,0,0,2.35,0.25]`、正解軌跡の生成値は`[0.3,-0.35,0.25,0.2,2.6,0.45]`。論文から得たパラメータではない。位相は32個、`2*pi*i/N`として重複する終端を含めない。残差を`1/sqrt(N)`で正規化してEq. (2)の積分を近似する。

状態は公開`gaussNewton`で各位相を解き、前の位相の状態を初期値にする。状態ソルバーの停止閾値は`1e-13`、状態の独立した制約検査は`1e-11`。二つの円の交点から得る別実装はターゲット生成と検証にだけ使用し、最適化内部の状態を置換しない。

ターゲットは到達可能なものと、座標に振幅0.02の3倍周波数を加えたものを比較する。後者はゼロ残差を前提にせず、停留性とコスト減少を見る。全体的な最適性や正解パラメータの一意性は主張しない。

## 比較と精度判定

- **BFGS + IFT (paper)**: 公開BFGSにEq. (3-4)の勾配を与える。`C_s`とマーカーの偏微分は解析、`C_p`だけ固定状態で中央差分。差分幅`1e-5`。
- **BFGS + public IFT**: 公開`computeEffectiveJacobian`で同じ勾配を作る。手書きの2×2感度実装とは独立に照合する。
- **BFGS + redundant IFT**: 元の制約`C`と`2C`を連結し、状態の求解と感度計算の両方で縦長の制約系を使う。単に制約を無視する実験ではない。
- **BFGS + full FD**: コストの中央差分。設計変数ごとの摂動で機構の全位相を解き直す。
- **Adjoint BFGS**: 既存の随伴とBFGS、一次偏微分は解析式。
- **Constrained GN / LM**: 既存の有効ヤコビアン、一次偏微分は解析式。論文のBFGSとは異なる比較対象。

全手法の上限は600設計反復、勾配閾値`1e-9`、制約閾値`1e-9`。LMのステップ・残差閾値は`1e-12`。状態の初期求解は全手法の計時内、最終検証と出力は計時外とする。

到達可能なターゲットでは、訓練位相と未使用の257個のずらした位相の両方で位置のRMS誤差`<=1e-5`を要求する。これは座標ごとのRMSではなく、点のユークリッド距離のRMS。さらに元の制約ノルム`<=1e-9`、戻り値の状態が正しい機構分岐上にあることを確認する。

歪めたターゲットでは、コスト減少率95%以上、幾何学的に再計算した縮約勾配ノルム`<=1e-8`を要求する。実現可能性・分岐の基準も同じ。`result.converged`を成功条件には使わない。

勾配比較では同じ初期点を使い、各呼び出しに現在状態の求解を含める。IFTは各位相1回、全コスト中央差分は各位相`2p=12`回の求解を必要とする。勾配の一致は解析的なIFT実装と照合する。回帰テストでは随伴と全コスト差分も独立に照合し、すべての一次偏微分、位相積分の正規化、冗長制約を検証する。

時間は実装と環境に依存する。参照・公開IFTは位相ごとの小さな系、既存の制約付きソルバーは全位相をまとめた密行列を扱うので、差は感度計算の理論的優劣だけでは説明できない。`effectiveJacobian.ts`は本ブランチで複数右辺の一括求解に変更し、正方系はLU、縦長系はQRを1回使用する。特異・不足制約系では既存の正則化・最小ノルム経路を維持する。全位相のブロック構造はまだ利用しない。論文§7.1の「勾配20–30倍高速化」をこのExampleで確認したとはみなさない。

## 観測結果と制限

最初の検証ではBFGS系が600反復に達し、未使用位相のRMS誤差が約`3.9e-5`で精度基準に未達だった。本ブランチではその同じ問題・初期値・精度基準で次の結果を得た。

| 手法 | 変更前の反復数 / 未使用位相RMS | 本ブランチの反復数 / 未使用位相RMS |
|---|---|---|
| BFGS + IFT (paper) | 600 / `3.856e-5`（未達） | 52 / `1.116e-10` |
| BFGS + full FD | 600 / `3.856e-5`（未達） | 52 / `2.941e-10` |
| Adjoint BFGS | 600 / `3.855e-5`（未達） | 51 / `7.449e-11` |
| BFGS + public IFT | 公開APIなし | 52 / `1.116e-10` |
| BFGS + redundant IFT | 未検証 | 52 / `1.116e-10` |
| Constrained GN | 4 / `4.404e-11` | 4 / `4.404e-11` |
| Constrained LM | 7 / `2.058e-10` | 7 / `2.058e-10` |

歪めたターゲットでも全7手法が基準を満たした。BFGSの前進感度経路は49反復、Adjoint BFGSは48反復で、独立に再計算した勾配ノルムが約`9.3e-10`となった。RMS残差は約0.02であり、ゼロ残差ではなく局所的な停留性を確認した結果である。

原因の検証では、変更前のBFGS更新が正の曲率でも`step^T * gradientChange <= 1e-10`で単位行列に戻り、小さいステップのセカント条件を満たさなくなることを回帰テストで再現した。相対的な角度条件`(s^T y)/(||s||||y||) > 1e-10`へ変更し、非有限・非正・極めて直交したペアを拒否する。密BFGSは不適切なペアをスキップして直前の有効なモデルを維持する。非降下方向を検出した場合のリセットは残る。L-BFGSも同じ相対判定を利用する。相対判定は目的関数の単位への依存を減らすが、初期逆Hessianや停止閾値まで自動的に尺度不変にするものではない。

追加検証には、目的スケール`1e-6,1,1e6`のBFGS/L-BFGS、正方・冗長制約での全右辺1回の求解、近接従属する縦長行列、すべての偏微分の形状チェック、呼び出し側行列の不変性を含む。近接従属ケースでは正規方程式ではなくQRで感度を計算する。

変更前のJSON/Markdownは`benchmark-results/mechanical-character-before.{json,md}`、現在の詳細は`benchmark-results/mechanical-character.{json,md}`に保存した。前者は前回検証の同一機での計測であり、未コミットの初期Exampleを含む。現在のJSONには環境・全試行・主要ソースのSHA-256を記録する。変更前後で精度達成状況が違うため、最適化時間の比だけを同一精度での高速化と解釈しない。

本検証で確かめたのは、正則な4節リンクと局所最適化の数値的な挙動である。任意の機構・初期値での収束や、特異姿勢・分岐を横断する探索は保証しない。一般の不等式付き最適化や学習機能は、実際の対象と必要条件を決めてから検討する。
