# 論文を基準にした連続機構最適化の検証

対象は[Coros et al., Computational Design of Mechanical Characters (2013)](https://publications.ri.cmu.edu/storage/publications/pub_files/2013/0/CDMC_final.pdf)。PDFの4–5ページ（§3.2・§4.2、式1–4）と9ページ（§7.1）を確認し、前の3寸法Exampleより検証範囲を広げた。**連続最適化の数式・機構クラスに沿った検証であり、著者のキャラクターデータや論文全体の追試ではない。**

## 論文との対応

| 論文の内容 | 今回の検証 | 判定と範囲 |
|---|---|---|
| §3.2、式1：閉路制約から状態を求める | 毎回公開GNで数値組立。独立した円交点解で状態・分岐・制約を照合 | 状態求解の目的は対応。論文のNewton-Raphsonと同じ実装ではない |
| §4.2、式2：入力位相に対応したマーカー位置誤差を積分 | `t=theta/(2*pi)`として一周期を正規化。8–128点の求積を独立4096点と照合 | 位相付きの目的関数を検証。§5の曲線検索メトリックは使わない |
| §4.2、式3：マーカーへの直接効果と状態経由の効果を足す | 二つの項を片方ずつ省いた負の対照実験、マーカーだけを動かす実験 | 正しい式はテイラー残差が二次、省略した式は一次となる |
| §4.2、式4：`C_s S=-C_p`による状態感度 | 公開有効ヤコビアン、別の解析求解、全コスト中央差分を照合 | 9設定で一致。状態が制約上にあり、`C_s`が列フルランクである範囲 |
| §4.2：冗長制約で擬似逆を使う | 整合する`[C,2C]`の縦長系でも縮約勾配を照合 | 微分の同値性を確認。論文の全3Dピン接続モデルの再現ではない |
| Fig.4・§7.1：二つの入力を比率−2、−1、1、2で駆動 | 駆動五節リンクを6変数・8変数で構成 | 同じ種類の周期的駆動を検証。図の寸法を復元したものではない |
| §4.2：BFGSで連続パラメータ最適化 | 9設定×2目標×3初期値と、9設定の全差分BFGS比較 | 単一初期値の一階条件を厳しく見ると2条件に問題を検出 |
| §4の初期化・§7.1の初期値に関する記述 | 固定した3初期値のうち、目的関数が最小の候補を選ぶ | 18目標設定で基準達成。データベース構築・検索自体は未再現 |
| §7.1：勾配を全差分より20–30倍高速に計算 | **勾配1回**を、現在状態の求解を含める場合と既知状態を使う場合に分けて計時 | 求解込みは約5–8倍、既知状態では約8–13倍。20–30倍という数値結果は未再現 |

論文の公式[プロジェクトページ](https://studios.disneyresearch.com/2013/07/21/computational-design-of-mechanical-characters/)で確認した公開先はPDFと動画であり、そのページから元の寸法・目標軌跡・初期値の数値ファイルは取得できなかった。今回の入力は明示した合成データである。

## 追加した機構

従来の6変数四節リンクに加え、2本のクランクで駆動する五節リンクを使う。

```text
A = a*[cos(theta), sin(theta)]
E = [g,0] + d*[cos(k*theta+delta), sin(k*theta+delta)]
C = A + b*[cos(beta),sin(beta)] - E - c*[cos(gamma),sin(gamma)]
marker = A + u*[cos(beta),sin(beta)] + v*[-sin(beta),cos(beta)]
```

角速度比kは−2、−1、1、2のいずれか。6変数では`[a,b,c,d,u,v]`を、8変数では支点間隔gと第2入力の初期位相deltaも調整する。状態は各位相の`[beta,gamma]`。二つの入力クランクを含む剛体全体の姿勢状態を、既知の入力と2つの未知角へ縮約した平面モデルである。実際の歯形・噛み合い・トルクは評価しない。

8変数の物理量は`center+range*tanh(p)`で表し、中心は`[0.45,2.1,1.8,2.4,0.35,0.35,2.6,0.45]`、範囲は`[0.08,0.1,0.1,0.1,0.06,0.25,0.3,0.2]`。順序は`[a,b,c,g,d,delta,u,v]`。円中心間距離は常に`[1.36,3.44]`内で、`|b-c|<=0.5`、`b+c>=3.7`となるため、三角形の退化と組立分岐の横断を避ける。

目標生成値は`[0.3,-0.35,0.25,0.2,-0.2,-0.3,0.4,0.3]`。既知解から作った目標と、それに`0.02*[cos(3*theta),sin(3*theta)]`を加えた変形目標を使う。ソルバーに渡すのは固定した目標座標で、正解寸法は最適化の初期値として渡さない。

## 検証手順

- 初期値は各モデルの基準値と、それに`+/-0.6*sin(i+1)`を加えた2点。結果を見て成功する初期値だけを選んだものではない。
- 最適化は32位相、BFGS上限800反復、変換後設計勾配の許容値`1e-10`。状態求解はGNの許容値`1e-13`に加えて、独立した閉路検査を行う。
- 位置検証は最適化格子と重ならない257位相（オフセット0.37）。数値組立と、独立した円交点による状態・位置を照合する。
- 到達可能目標は未使用位相の最大位置誤差`<=1e-5`。変形目標は目的関数減少と独立勾配ノルム`<=1e-8`。両方で閉路・分岐誤差`<=1e-9`、周期性、履歴のコスト再計算一致を要求する。
- **変数変換の飽和を別に検査する。** 有界変数を`q=tanh(p)`へ戻し、中央差分または境界内向きの3点片側差分で、閉区間`[-1,1]`内の射影勾配残差を計算する。基準は`<=1e-6`。物理量はqのアフィン関数なので、これは元の寸法の境界付近で改善方向が残るかの検査となる。大域最適性の証明ではない。
- 勾配計時は9設定×16/32/128位相×2種類の状態準備×2手法。毎回新しい評価器を使い、ウォームアップ2回を捨て7回計測する。756計測の中央値・IQRと生データを保存する。既知状態の場合は、両手法とも現在コストを計時前に1回計算し、その後の追加組立だけを計測する。目標生成・独立検証・描画は計時外。論文にはこの計時境界の詳細がなく、いずれも元実験と同条件と断定しない。

## 観測結果

| 検証 | 結果 |
|---|---|
| 式3–4・負の対照・冗長制約 | 9/9設定で基準達成。公開IFT勾配と独立解析式の最大絶対差は約`3.4e-12` |
| 到達可能目標 | 36/36条件で基準達成。未使用位相のRMS誤差は最大約`1.5e-9`、最大位置誤差は約`2.7e-9` |
| 変形目標 | 変換後勾配までなら27/27条件が基準内。元の寸法の一階条件も加えると25/27条件 |
| 単一初期値の全検証 | **61/63条件が合格、2条件が不合格**。54条件の公開IFT+BFGSと9条件の全差分BFGSの合計 |
| 3初期値の最小コスト候補 | 18/18目標設定で基準達成。合格フラグを使って選ぶのではなく、再計算した目的関数が最小の候補を選択 |
| 位相求積 | 32点と独立4096点の初期目的関数差は最大約`5.5e-15`、勾配差は約`8.0e-14`。この滑らかな設計範囲に限る |
| 勾配計算量 | 現在状態の求解込みではIFTがN回、中央全差分が`2*p*N`回。既知状態ならIFTの追加組立は0回。32位相・8変数では32回/0回対512回 |
| 勾配計算時間 | 求解込みで約5–8倍、既知状態で約8–13倍。論文の20–30倍と同じ結果は得ていない |

全366ユニットテストは通過した。これには変数変換による見かけの収束を拒否するテストも含む。ベンチマークは不合格の単一初期値が残るため、**現在は意図どおり終了コード1**を返す。成功ケースだけを数え直して終了コード0にする処理は入れていない。

### 不合格となった2条件

どちらも8変数・角速度比−1・変形目標で、初期値0と2の場合。連接棒などの有界寸法が飽和し、`tanh`の微分がほぼゼロになる。変換後の勾配は小さくBFGSは収束を返すが、元の寸法の射影勾配残差は約`2.62e-6`で、改善方向が残る。RMS誤差は約`0.0197071`。

同じ目標を初期値1から解くと、射影勾配残差は約`7.5e-10`、RMS誤差は約`0.0197015`となり、より小さい目的関数の解が得られる。この検証は、BFGSが与えられたp座標の勾配を誤計算したという意味ではない。**寸法の再パラメータ化と収束判定を合わせて検討する必要がある**という反例である。

ほかに4条件ではBFGSの収束フラグがfalseとなったが、独立精度基準は満たした。ソルバーの`1e-10`勾配基準と検証の`1e-8`基準は異なるので、フラグと精度を別の列に保存している。

## 結論と未再現部分

論文の式2–4に基づく軌跡フィッティングと、全差分に対して状態求解回数を削減する効果は確認できた。軌跡が複雑な駆動五節リンクでも、到達可能な目標を現状APIで再現できる。一方で、単一初期値の収束フラグだけから、寸法の良い最適解が得られたと結論することはできない。初期化の影響を評価し、元の寸法で独立検証する必要がある。

論文の元の寸法・キャラクター・Fig.5右の被駆動キャラクター上のマーカー、データベース検索、非円形歯車、3D機構、干渉・支持構造・製造は未再現。初期値選択の実験はデータベース検索の代用を再現したものではない。学習・SQPは追加していない。
